# لوحة مخزون أصناف التغذية العلاجية – تجمع الشرقية الصحي

Therapeutic Nutrition Inventory – Eastern Health Cluster

- النسخة العربية: https://khaled1407ss-eng.github.io/ehc-nutrition-dashboard/ar/
- English version: https://khaled1407ss-eng.github.io/ehc-nutrition-dashboard/en/

تعرض اللوحة أرصدة أصناف التغذية العلاجية في مستودع التجمع، وتربطها بالقائمة الأساسية المعتمدة، وتبيّن البديل الممكن لكل صنف ورصيده، والنواقص وحالة الطرح، مع وصف علمي لكل صنف.

- **قبل الشراء المباشر:** جدول بجميع الأصناف وأرصدتها، يُبحث فيه بالاسم أو الرقم الوزاري أو كود نبكو.
- **التحقق قبل الشراء المباشر:** خطوات نموذج الحوكمة بالترتيب ونتيجتها لكل صنف.
- **طلب الرأي الفني:** يُجهَّز ببيانات الصنف وجدول البدائل المتوفرة بالرقم الوزاري وكود نبكو والرصيد، ويُنسخ جدولاً للبريد أو نصاً للواتساب.
